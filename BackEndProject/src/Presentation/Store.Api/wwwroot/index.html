بک‌اند فروشگاه مبلمان و دکوراسیون

Diba Gallery یک پلتفرم API برای فروش آنلاین مبلمان، فرش و دکوراسیون منزل است — از کاتالوگ و لیست علاقه‌مندی تا سبد خرید، پرداخت، CMS، بلاگ، استوری کاربران و پنل ادمین، با وب‌سرویس RESTful برای اتصال به وب‌سایت React و اپلیکیشن‌های موبایل.

چرا Diba Gallery؟

بک‌اندی که تجربه خرید یک فروشگاه دکوراسیون مدرن را پشتیبانی می‌کند — از مرور دسته‌بندی‌ها و مقایسه محصول تا checkout، پیگیری سفارش و مدیریت محتوا.

🛋️

کاتالوگ تخصصی دکوراسیون

دسته‌بندی چندسطحی، ویژگی محصول، تصاویر، توضیحات، تخفیف، جستجو و لیستینگ — متناسب با مبلمان، فرش، روشنایی و اکسسوری منزل.

🔗

یکپارچه با فرانت React

API استاندارد برای وب‌سایت SSR، PWA و داشبورد کاربر/ادمین. مستندات OpenAPI، نمونه درخواست و محیط تست برای تیم توسعه.

🛡️

امنیت و مقیاس‌پذیری

احراز هویت JWT، مدیریت نشست، RBAC با permission داینامیک، Content Policy و معماری لایه‌ای برای رشد تدریجی بدون فروپاشی ساختار.

معماری و الگوها

  • Clean Architecture با جداسازی Domain، Application و Infrastructure
  • CQRS با MediatR و FluentValidation
  • Repository Pattern و Unit of Work
  • API Versioning (v1) و پاسخ یکپارچه ApiResult
  • Localization فارسی و انگلیسی با Accept-Language

امنیت و مستندات

  • JWT Bearer و OAuth2 در Swagger
  • مدیریت نشست و کنترل توکن مسدودشده
  • RBAC ادمین با Permission از روی کنترلر
  • مستندات OpenAPI 3 با توضیحات XML از کد
  • Content-Type استاندارد application/json
